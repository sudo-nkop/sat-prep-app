# SAT Prep Folder

A self-contained study set for the **Digital SAT** (the current format as of 2024+).

## Folder layout

- `cheatsheets/` — quick-reference sheets for math, grammar, and reading
- `math-practice/` — practice sets organized by topic
- `reading-writing-practice/` — reading comprehension + grammar/writing exercises
- `sample-exercises/` — mixed mini-sections that mimic the real test
- `answer-keys/` — solutions and explanations for everything above

## Suggested study plan (4 weeks)

1. **Week 1** — Read all cheatsheets, do `math-practice/01-algebra.md` and `reading-writing-practice/01-grammar-basics.md`.
2. **Week 2** — `math-practice/02-advanced-math.md` and `reading-writing-practice/02-reading-comprehension.md`.
3. **Week 3** — `math-practice/03-problem-solving.md` and `reading-writing-practice/03-rhetoric.md`.
4. **Week 4** — `sample-exercises/` under timed conditions, then review every miss in `answer-keys/`.

## About the Digital SAT

- **Reading & Writing**: 2 modules, 27 questions each, 32 min each (64 min total)
- **Math**: 2 modules, 22 questions each, 35 min each (70 min total)
- **Adaptive**: Module 2 difficulty depends on Module 1 performance
- **Calculator**: allowed on the entire Math section (Desmos built in)
- Total score: 400–1600

## Free official resources to pair with this folder

- **Khan Academy → Official Digital SAT Prep** — free, partnered with College Board
