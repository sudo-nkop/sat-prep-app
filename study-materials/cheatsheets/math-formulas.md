# SAT Math Formula Cheatsheet

The SAT gives you a reference sheet, but **memorize these** — looking up wastes time.

## Given on the test (still memorize)

```
Area of circle:        A = πr²
Circumference:         C = 2πr
Area of rectangle:     A = lw
Area of triangle:      A = ½bh
Pythagorean theorem:   a² + b² = c²
Special right triangles:
   30-60-90: sides x, x√3, 2x
   45-45-90: sides x, x, x√2
Volume of box:         V = lwh
Volume of cylinder:    V = πr²h
Volume of sphere:      V = (4/3)πr³
Volume of cone:        V = (1/3)πr²h
Volume of pyramid:     V = (1/3)lwh
```

There are 360° in a circle, 2π radians in a circle, and the sum of angles in a triangle is 180°.

## NOT given — memorize these

### Algebra
```
Slope:                 m = (y₂ − y₁) / (x₂ − x₁)
Slope-intercept:       y = mx + b
Point-slope:           y − y₁ = m(x − x₁)
Standard form:         Ax + By = C
Distance:              d = √[(x₂−x₁)² + (y₂−y₁)²]
Midpoint:              M = ((x₁+x₂)/2, (y₁+y₂)/2)
Quadratic formula:     x = (−b ± √(b²−4ac)) / 2a
Discriminant:          Δ = b² − 4ac
   Δ > 0 → two real roots
   Δ = 0 → one real root
   Δ < 0 → no real roots
Vertex of parabola:    x = −b/(2a)
Sum of roots:          −b/a
Product of roots:      c/a
```

### Exponents
```
xᵃ · xᵇ = xᵃ⁺ᵇ
xᵃ / xᵇ = xᵃ⁻ᵇ
(xᵃ)ᵇ = xᵃᵇ
x⁻ᵃ = 1/xᵃ
x^(a/b) = ᵇ√(xᵃ)
x⁰ = 1   (x ≠ 0)
```

### Percents
```
Percent change = (new − old) / old × 100
Increase by p%: multiply by (1 + p/100)
Decrease by p%: multiply by (1 − p/100)
```

### Statistics
```
Mean = sum / count
Median = middle value (sorted)
Mode = most frequent
Range = max − min
Standard deviation: lower SD = data closer to mean
```

### Circles (coordinate)
```
(x − h)² + (y − k)² = r²    (center (h,k), radius r)
Arc length:   s = rθ        (θ in radians)
Sector area:  A = ½r²θ      (θ in radians)
```

### Trigonometry
```
SOH CAH TOA
sin θ = opposite / hypotenuse
cos θ = adjacent / hypotenuse
tan θ = opposite / adjacent
sin²θ + cos²θ = 1
sin(θ) = cos(90° − θ)
```

### Linear functions — quick checks
- Two lines are **parallel** if slopes equal.
- Two lines are **perpendicular** if slopes multiply to −1.
- A system has **no solution** if lines are parallel but not identical.
- A system has **infinite solutions** if equations are scalar multiples.

### Function transformations
```
f(x) + k    shifts up k
f(x) − k    shifts down k
f(x − h)    shifts right h
f(x + h)    shifts left h
−f(x)       reflects over x-axis
f(−x)       reflects over y-axis
a · f(x)    vertical stretch (|a|>1) or compress
```

## Desmos tips (built-in calculator)

- Type the equation; Desmos graphs it instantly.
- Click intersection points to get exact coordinates.
- For systems, just type both equations.
- For "what value of k makes the system have one solution," graph and slide a slider.
- Tables: type `x` and `f(x)` in a table to evaluate at multiple points.
